# Changelog

All notable changes to BlueScrubsPrep will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - 2025-06-26

### Major Changes
- **Complete brand update** from NHSprep to BlueScrubsPrep
- **Professional PLAB Preparation** positioning as core messaging
- **Comprehensive documentation overhaul** with updated branding

### Added
- Hero banner badge with "Professional PLAB Preparation" text (enlarged for visibility)
- Desktop "More" dropdown navigation with comprehensive menu items
- Interactive 3D Human Anatomy section with Zygote Body integration (later removed)
- Enhanced visual explanation formatting with professional icons
- Structured answer explanations with color-coded sections
- Memory aid bullet points with yellow markers
- Team section with complete professional backgrounds
- NICE NG136 clinical guide integration with overlay
- Advanced AI features with adaptive learning algorithms
- Option letter styling with consistent red circular badges

### Improved
- **Hero banner optimization** with video background and minimal text overlay
- **Mobile navigation** with iPhone-style design and sticky bottom controls
- **Text contrast and readability** across all interfaces
- **Adaptive learning cards** with lighter background colors for better visibility
- **Question navigation** with prominent Previous/Next buttons
- **Answer explanations** with structured formatting and bullet points
- **NICE visual summary** integration for enhanced clinical guidance

### Fixed
- **Text visibility issues** on dashboard cards with CSS overrides
- **AI tutor text color** with forced black styling for maximum visibility
- **Mobile landscape navigation** text overlap in iPhone 15 Pro Max
- **Option letter styling** consistency across all test interfaces
- **Broken medical guideline links** with verified UK alternatives
- **Green box visibility** with proper CSS width and margin fixes

### Removed
- Interactive 3D Human Anatomy section from PLAB 2 page bottom
- All Anthropic Claude AI integration dependencies
- Non-functional auto-translate feature
- Broken reference URLs and replaced with verified alternatives

## [1.9.0] - 2025-06-25

### Added
- **5,528 authentic medical questions** generated across 11 specialties
- **3,898 OSCE stations** with streamlined user format
- **International exam support** for USMLE, AMC, MCCQE systems
- **39-language translation system** with built-in medical dictionary
- **Complete AI independence** with hybrid system deployment

### Enhanced
- **Question generation system** with template-based quality standards
- **OSCE station format** with actor scripts and practical mark schemes
- **Global medical exam compatibility** with country-specific adaptations
- **Independent content system** without external API dependencies

## [1.8.0] - 2025-06-24

### Major Features
- **AI-powered question generation** with OpenAI GPT-4o integration
- **Video hero banner** implementation with medical professional content
- **Cost calculator** and generation status monitoring
- **Batch processing system** for large-scale content creation

### Content Expansion
- **8 authentic medical questions** baseline with cardiovascular scenarios
- **Verified UK guideline links** for NICE, CKS, GMC standards
- **Comprehensive medical scenarios** with detailed explanations
- **Enhanced navigation** with prominent question controls

## [1.7.0] - 2025-06-23

### Infrastructure
- **Initial BlueScrubsPrep setup** with comprehensive PLAB preparation platform
- **Database architecture** with PostgreSQL and Drizzle ORM
- **Authentication system** with Replit Auth integration
- **Responsive design** with Tailwind CSS and Radix UI components

### Core Features
- **PLAB 1 MCQ system** with authentic medical questions
- **PLAB 2 OSCE stations** with clinical scenarios
- **Neurodiversity accommodations** with 8 support types
- **Multi-language support** for international medical graduates

### Medical Content
- **UK medical guidelines integration** (NICE, CKS, GMC, BNF)
- **Clinical question bank** with specialty-specific content
- **OSCE practice stations** with marking criteria
- **Educational resources** with mnemonics and memory aids
